# WinFM2008 機能対応表

WinFM2008 のヘルプ（WinFMx64.chm）に記載の機能と、FDLike2026 の実装状況。
○ = 実装済み　△ = 一部 / 代替手段あり　× = 未実装　－ = 対象外（Win11 では不要・時代遅れ）

## 各操作

| WinFM2008 | FDLike2026 |
|---|---|
| ランチバー（2 本 × 4 ページ、Shift+F1～） | × |
| WinFMTree（独自ツリー、キー操作） | ○ T でツリーモード（↑↓←→ Space Enter Esc L K Shift+英字 1～0） |
| コマンドマクロ（F2、$ 置換、最大 100） | ○ 35 スロット（A～Z, 1～9） |
| 拡張子の関連づけ（F4） | ○ ワイルドカード・複数拡張子・$ マクロ対応 |
| ジャンプフォルダ（F01～F09 / A～Z / 0～9、\ で登録、Del で削除） | ○ F1～F12 / A～Z（0～9 は未）、Space/Ins で登録、Del で削除、クリック / 右クリック対応 |
| 複写・移動ダイアログ（宛先入力、ジャンプ、フィルタ、上書き時の方法選択、更新のみ…） | ○ 自前エンジン。上書き時の「複写・移動の方法」ダイアログ（以後同設定）あり |
| 圧縮 / 解凍（LZH, ZIP, CAB, TAR, RAR…） | △ zip のみ（V で中身表示も） |
| ファイルの分割と連結 | × |
| ファイル名の一括変換（連番） | ○ Shift+N、プレビュー付き |
| ミラーコピー（フィルタ、事前確認、手順の保存） | ○ robocopy /MIR のフロントエンド |
| コマンドの実行（DosRun32、別ユーザー） | ○ 一時停止あり/なし、別ユーザー（管理者）実行 |
| ファイルの検索（名前、場所、サブフォルダ、結果から操作） | ○ 結果の右クリック操作は未 |
| コピー＆ペースト | ○ |

## カスタマイズ

| タブ | WinFM2008 | FDLike2026 |
|---|---|---|
| リスト | 5 表示モード、フォルダ表記、ファイル名の幅、拡張子分離、日付形式、サイズ/属性の表示有無 | ○ Shift+1～5 で 5 モード、F10 › リスト で設定。加えて FDLike 独自でモードごとに右ウィンドウの表示/非表示 |
| ツール | テキスト/バイナリエディタ、ビューア、画像ビューア、アーカイバ（起動オプション、ジャンプオプション %L %F） | △ テキストエディタのみ |
| デザイン | 配色（名前付き）、部位ごとの色、RGB、壁紙、透過、領域別フォント、行間、タグマーク | ○ 壁紙・透過以外 |
| 起動 | 起動時フォルダ、非表示属性、並び順、ロゴ、トレイ常駐 | △ 前回フォルダ・隠し表示・隠しの並び |
| 操作 | Enter の動作（修飾キー別）、ダイアログ、イニシャルサーチ、効果音、クリックで名前変更、カーソルキー（サイクリック等） | × |
| 設定1 | ソートの種類（標準 / エクスプローラ / FILMTN…）、オプション、パス入力時のツリー、音声ガイド、アイコンキャッシュ、/ キー | △ 隠しのグループ化のみ |
| 設定2 | フォルダ更新監視（間隔、フォーカス時再読込、タグ解除）、共有フォルダアクセス | ○ 監視は常時（FileSystemWatcher）+ 前面化時 |
| 詳細 | 削除の確認・ダイアログ形式・既定ボタン、コピー/移動の詳細、インプレース編集、特殊キー割り当て | × |
| ツールバー | タイプ、ボタン | × ツールバーなし（キーボード主体） |
